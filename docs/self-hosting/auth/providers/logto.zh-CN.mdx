# 配置 Logto 身份验证

[Logto](https://logto.io/) 是一个开源的 Auth0 替代方案，专为现代应用和 SaaS 产品设计。

<Steps>
  ### 在 Logto 中创建应用

  1. 登录 Logto 控制台
  2. 前往 **Applications**，点击 **Create application**
  3. 选择 **Traditional web** 作为应用类型
  4. 填写应用名称：`LobeHub`
  5. 配置重定向 URI：

  <Callout type={'info'}>
    **回调 URL 格式**: `https://your-domain.com/t/<tenant>/api/auth/callback/logto`
  </Callout>

  6. 创建后，记下 **App ID** 和 **App Secret**

  ### 获取 Issuer URL

  Issuer URL 是 Logto 端点，通常为：

  - 云版：`https://your-tenant.logto.app/oidc`
  - 自托管：`https://your-logto-domain/oidc`

  ### 在 Admin 中配置

  SSO 由每个租户在 Admin 中配置，不再使用环境变量。在 Admin 中打开该租户的 SSO 提供商，新增一个提供商并填写：

  | 字段            | 值                                       |
  | ------------- | --------------------------------------- |
  | 协议            | OIDC                                    |
  | 提供商 ID        | 填 `logto` 使用 logto 预设；其他 ID 按普通 OIDC 处理 |
  | Client ID     | 身份提供商的 Client ID                        |
  | Client Secret | 身份提供商的 Client Secret；Admin 加密保存         |
  | Issuer        | `https://<tenant>.logto.app/oidc`       |

  需要在身份提供商处登记的回调 URL 为 `https://your-domain.com/t/<租户>/api/auth/callback/<提供商 ID>`，Admin 会为每个提供商显示该地址。
</Steps>

<Callout type={'info'}>部署成功后，用户将可以通过 Logto 身份认证并使用 LobeHub。</Callout>
