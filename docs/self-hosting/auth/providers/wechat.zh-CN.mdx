# 配置微信身份验证

[微信开放平台](https://open.weixin.qq.com/) 支持第三方应用接入微信登录功能。

<Callout type={'warning'}>
  微信网页登录需要经过认证的微信开放平台账号，以及通过微信审核的网站应用。此流程需要在中国进行企业认证。
</Callout>

<Steps>
  ### 在微信开放平台创建网站应用

  1. 前往 [微信开放平台](https://open.weixin.qq.com/)
  2. 注册并验证开发者账号
  3. 前往 **管理中心** > **网站应用**
  4. 点击 **创建网站应用**
  5. 填写应用信息并提交审核

  ### 配置 OAuth 设置

  应用审核通过后：

  1. 进入应用设置
  2. 在 **网站信息** 中配置回调域名

  <Callout type={'info'}>
    回调域名格式：

    - **回调域名**: `your-domain.com`（不含协议和路径）
    - **完整回调 URL**: `https://your-domain.com/t/<tenant>/api/auth/callback/wechat`
  </Callout>

  3. 记下 **AppID** 和 **AppSecret**

  ### 在 Admin 中配置

  SSO 由每个租户在 Admin 中配置，不再使用环境变量。在 Admin 中打开该租户的 SSO 提供商，新增一个提供商并填写：

  | 字段            | 值                                              |
  | ------------- | ---------------------------------------------- |
  | 协议            | OIDC                                           |
  | 提供商 ID        | 填 `wechat` 使用 wechat 预设；其他 ID 按普通 OIDC 处理      |
  | Client ID     | 身份提供商的 Client ID                               |
  | Client Secret | 身份提供商的 Client Secret；Admin 加密保存                |
  | Issuer        | `https://open.weixin.qq.com`（Admin 要求填写，不用于发现） |

  需要在身份提供商处登记的回调 URL 为 `https://your-domain.com/t/<租户>/api/auth/callback/<提供商 ID>`，Admin 会为每个提供商显示该地址。

  <Callout type={'info'}>
    Admin 没有微信的 OAuth 2.0 预设，所以以 OIDC 条目添加，提供商 ID 填 `wechat`；LobeHub 对这个 ID 使用内置的微信预设。
  </Callout>
</Steps>

<Callout type={'info'}>
  部署成功后，用户将可以通过微信身份认证并使用 LobeHub。
</Callout>

## 注意事项

- 微信登录使用扫码方式，用户需要使用微信手机端扫码
- 需要经过认证的微信开放平台账号
- 回调域名需要在中国进行 ICP 备案
