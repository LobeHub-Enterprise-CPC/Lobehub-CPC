# 配置 Keycloak 身份验证

[Keycloak](https://www.keycloak.org/) 是一个开源的身份和访问管理解决方案。

<Steps>
  ### 在 Keycloak 中创建客户端

  1. 登录 Keycloak 管理控制台
  2. 选择你的 realm（或创建新的）
  3. 前往 **Clients** > **Create client**
  4. 配置客户端：
     - **Client type**: `OpenID Connect`
     - **Client ID**: `lobechat`（或任意名称）
  5. 点击 **Next**
  6. 启用 **Client authentication**（On）
  7. 点击 **Next** 然后 **Save**

  ### 配置重定向 URI

  在客户端 **Settings** 标签页中：

  1. 在 **Valid redirect URIs** 下添加重定向 URI

  <Callout type={'info'}>
    回调 URL 格式：

    - 本地开发: `http://localhost:3210/t/<tenant>/api/auth/callback/keycloak`
    - 生产环境: `https://your-domain.com/t/<tenant>/api/auth/callback/keycloak`
  </Callout>

  ### 获取客户端密钥

  前往 **Credentials** 标签页复制 **Client secret**。

  ### 获取 Issuer URL

  Issuer URL 格式：`https://your-keycloak-domain/realms/your-realm`

  例如：`https://keycloak.example.com/realms/master`

  ### 在 Admin 中配置

  SSO 由每个租户在 Admin 中配置，不再使用环境变量。在 Admin 中打开该租户的 SSO 提供商，新增一个提供商并填写：

  | 字段            | 值                                             |
  | ------------- | --------------------------------------------- |
  | 协议            | OIDC                                          |
  | 提供商 ID        | 填 `keycloak` 使用 keycloak 预设；其他 ID 按普通 OIDC 处理 |
  | Client ID     | 身份提供商的 Client ID                              |
  | Client Secret | 身份提供商的 Client Secret；Admin 加密保存               |
  | Issuer        | `https://keycloak.example.com/realms/<realm>` |

  需要在身份提供商处登记的回调 URL 为 `https://your-domain.com/t/<租户>/api/auth/callback/<提供商 ID>`，Admin 会为每个提供商显示该地址。
</Steps>

<Callout type={'info'}>
  部署成功后，用户将可以通过 Keycloak 身份认证并使用 LobeHub。
</Callout>
