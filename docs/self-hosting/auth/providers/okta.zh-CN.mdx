# 配置 Okta 身份验证

[Okta](https://www.okta.com/) 是领先的身份和访问管理平台。

<Steps>
  ### 在 Okta 中创建应用

  1. 登录 Okta 管理控制台
  2. 前往 **Applications** > **Applications**
  3. 点击 **Create App Integration**
  4. 选择：
     - Sign-in method: **OIDC - OpenID Connect**
     - Application type: **Web Application**
  5. 配置应用：
     - App integration name: `LobeHub`
     - Sign-in redirect URIs: 添加回调 URL

  <Callout type={'info'}>
    **回调 URL 格式**: `https://your-domain.com/t/<tenant>/api/auth/callback/okta`
  </Callout>

  6. 创建后，记下 **Client ID** 和 **Client Secret**

  ### 获取 Issuer URL

  Issuer URL 通常为：`https://your-okta-domain.okta.com`

  对于自定义授权服务器：`https://your-okta-domain.okta.com/oauth2/default`

  ### 在 Admin 中配置

  SSO 由每个租户在 Admin 中配置，不再使用环境变量。在 Admin 中打开该租户的 SSO 提供商，新增一个提供商并填写：

  | 字段            | 值                                     |
  | ------------- | ------------------------------------- |
  | 协议            | OIDC                                  |
  | 提供商 ID        | 填 `okta` 使用 okta 预设；其他 ID 按普通 OIDC 处理 |
  | Client ID     | 身份提供商的 Client ID                      |
  | Client Secret | 身份提供商的 Client Secret；Admin 加密保存       |
  | Issuer        | `https://<your-okta-domain>.okta.com` |

  需要在身份提供商处登记的回调 URL 为 `https://your-domain.com/t/<租户>/api/auth/callback/<提供商 ID>`，Admin 会为每个提供商显示该地址。
</Steps>

<Callout type={'info'}>部署成功后，用户将可以通过 Okta 身份认证并使用 LobeHub。</Callout>
