# 配置飞书身份验证

[飞书](https://www.feishu.cn/) 是字节跳动推出的企业协作平台。

<Steps>
  ### 在飞书开放平台创建应用

  1. 前往 [飞书开放平台](https://open.feishu.cn/)
  2. 点击 **创建应用** > **企业自建应用**
  3. 填写应用名称和描述
  4. 创建后，前往 **凭证与基础信息** 获取：
     - **App ID**
     - **App Secret**

  ### 配置 OAuth 权限

  1. 在应用设置中，前往 **安全设置**
  2. 添加重定向 URI

  <Callout type={'info'}>
    回调 URL 格式：

    - 本地开发: `http://localhost:3210/t/<tenant>/api/auth/callback/feishu`
    - 生产环境: `https://your-domain.com/t/<tenant>/api/auth/callback/feishu`
  </Callout>

  3. 前往 **权限管理** 添加：
     - `contact:user.email:readonly`（读取用户邮箱）
     - `contact:user.base:readonly`（读取用户基本信息）

  ### 发布应用

  1. 前往 **版本管理与发布**
  2. 创建新版本并提交审核
  3. 审核通过后，发布应用

  ### 在 Admin 中配置

  SSO 由每个租户在 Admin 中配置，不再使用环境变量。在 Admin 中打开该租户的 SSO 提供商，新增一个提供商并填写：

  | 字段            | 值                                |
  | ------------- | -------------------------------- |
  | 协议            | OAuth 2.0，预设选 **飞书**             |
  | 提供商 ID        | 任意 ID，例如 `feishu`；它是回调 URL 的最后一段 |
  | Client ID     | 身份提供商的 Client ID                 |
  | Client Secret | 身份提供商的 Client Secret；Admin 加密保存  |

  需要在身份提供商处登记的回调 URL 为 `https://your-domain.com/t/<租户>/api/auth/callback/<提供商 ID>`，Admin 会为每个提供商显示该地址。
</Steps>

<Callout type={'info'}>
  部署成功后，用户将可以通过飞书身份认证并使用 LobeHub。
</Callout>
