# 配置 Authelia 身份验证

[Authelia](https://www.authelia.com/) 是一个开源的身份验证和授权服务器，提供双因素认证和单点登录功能。

<Steps>
  ### 在 Authelia 中配置 OIDC 客户端

  在 Authelia 配置文件中添加新的 OIDC 客户端：

  ```yaml
  identity_providers:
    oidc:
      clients:
        - client_id: 'lobechat'
          client_name: 'LobeHub'
          client_secret: 'your-client-secret'
          redirect_uris:
            - 'https://your-domain.com/t/<tenant>/api/auth/callback/authelia'
          scopes:
            - 'openid'
            - 'profile'
            - 'email'
  ```

  <Callout type={'info'}>
    **回调 URL 格式**: `https://your-domain.com/t/<tenant>/api/auth/callback/authelia`
  </Callout>

  ### 在 Admin 中配置

  SSO 由每个租户在 Admin 中配置，不再使用环境变量。在 Admin 中打开该租户的 SSO 提供商，新增一个提供商并填写：

  | 字段            | 值                                             |
  | ------------- | --------------------------------------------- |
  | 协议            | OIDC                                          |
  | 提供商 ID        | 填 `authelia` 使用 authelia 预设；其他 ID 按普通 OIDC 处理 |
  | Client ID     | 身份提供商的 Client ID                              |
  | Client Secret | 身份提供商的 Client Secret；Admin 加密保存               |
  | Issuer        | `https://auth.example.com`                    |

  需要在身份提供商处登记的回调 URL 为 `https://your-domain.com/t/<租户>/api/auth/callback/<提供商 ID>`，Admin 会为每个提供商显示该地址。
</Steps>

<Callout type={'info'}>部署成功后，用户将可以通过 Authelia 身份认证并使用 LobeHub。</Callout>
