# 配置 Authentik 身份验证

[Authentik](https://goauthentik.io/) 是一个开源身份提供商，专注于灵活性和多功能性。

<Steps>
  ### 在 Authentik 中创建 OAuth2 提供商

  1. 在 Authentik 管理界面，前往 **Applications** > **Providers**
  2. 点击 **Create**，选择 **OAuth2/OpenID Provider**
  3. 配置提供商：
     - Name: `LobeHub`
     - Authorization flow: 选择授权流程
     - Client type: `Confidential`
     - Redirect URIs: 添加回调 URL

  <Callout type={'info'}>
    **回调 URL 格式**: `https://your-domain.com/t/<tenant>/api/auth/callback/authentik`
  </Callout>

  ### 创建应用

  1. 前往 **Applications** > **Applications**
  2. 点击 **Create**，关联到刚创建的 OAuth2 提供商
  3. 记下 **Client ID** 和 **Client Secret**

  ### 获取 Issuer URL

  Issuer URL 通常为：`https://your-authentik-domain/application/o/your-app-slug/`

  ### 在 Admin 中配置

  SSO 由每个租户在 Admin 中配置，不再使用环境变量。在 Admin 中打开该租户的 SSO 提供商，新增一个提供商并填写：

  | 字段            | 值                                                         |
  | ------------- | --------------------------------------------------------- |
  | 协议            | OIDC                                                      |
  | 提供商 ID        | 填 `authentik` 使用 authentik 预设；其他 ID 按普通 OIDC 处理           |
  | Client ID     | 身份提供商的 Client ID                                          |
  | Client Secret | 身份提供商的 Client Secret；Admin 加密保存                           |
  | Issuer        | `https://authentik.example.com/application/o/<app-slug>/` |

  需要在身份提供商处登记的回调 URL 为 `https://your-domain.com/t/<租户>/api/auth/callback/<提供商 ID>`，Admin 会为每个提供商显示该地址。
</Steps>

<Callout type={'info'}>部署成功后，用户将可以通过 Authentik 身份认证并使用 LobeHub。</Callout>
